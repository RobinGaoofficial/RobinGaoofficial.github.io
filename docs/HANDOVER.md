# 接手清单（AI / 人工维护）

## 第一次操作前

1. 阅读本目录的使用说明、开发文档及服务端说明，检查最新 git log；本清单记录于 2026-11-17，不替代现场状态。
2. 工作目录 E:\Backup\Blog\Robin-Blog；仓库 RobinGaoofficial/RobinGaoofficial.github.io，main。不要新建替代网站。
3. 查看 `git status --short`、暂存区和工作区差异。可能已有 README、about、模板、Obsidian 和图片改动，全部视为用户内容，未经要求不得覆盖或提交。
4. 不执行 reset --hard、clean、强制推送。不要通过整体 checkout 覆盖用户文件。
5. 修改 JavaScript 后必须 `npm test`；优先 pnpm；新增生产依赖先询问站主。当前需求不需要新依赖。

## 不应破坏的行为

- 首页搜索默认收起，组合过滤可无关键词，月份与日期范围互斥，保留排序/分页和 URL 恢复。
- 星球闭合 offset-path 末尾 Z、前后遮挡、减弱动画偏好必须保留。
- 相邻文章更新在左、更早在右，手机一致；手机页脚标语居中。
- 关于页与普通页面不加载阅读量/点赞/评论；只对 posts 集合启用。
- 评论必须登录；普通用户 QQ 资料空值与数字回复 ID 有补丁；管理员也不能编辑他人正文。
- Waline 界面不显示 Powered by，但不能删第三方许可。
- 支持邮箱 contact@gaobinbin.dev，不替换成个人邮箱，不擅改 SMTP 发件账户。
- 版权是字面量“©2026-至今 高彬斌”；RSS、地图、搜索允许规则与禁训练声明保持一致。
